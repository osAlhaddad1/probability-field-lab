What you think,
and how sure you are.

Each parameter takes three numbers. The best guess is the single value you would name if forced. The uncertainty is how far off that guess could plausibly be, as a percentage of it. The doubt about the doubt asks how much you trust that error bar — leave it at zero when you are confident in it, raise it when the error bar is itself a guess.
